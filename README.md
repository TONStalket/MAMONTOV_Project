# Mamontov.com — социальная сеть

Проект демонстрирует концепцию социальной сети **mamontov.com** с защищённым мессенджером, выполненный на Python и C++. Серверная часть реализована на Flask с использованием SQLite, фронтенд — адаптивные шаблоны на HTML/CSS/JS. Очистка сообщений перед сохранением выполняется отдельным модулем на C++.

## Возможности

- Регистрация пользователей с обязательным Gmail-адресом.
- Хеширование паролей и авторизация через сессии.
- Живой мессенджер с автообновлением сообщений без перезагрузки страницы.
- Современный интерфейс с адаптивной вёрсткой.
- Очистка пользовательского ввода при помощи C++-утилиты `message_sanitizer`.

## Установка и запуск

1. **Создайте виртуальное окружение и установите зависимости**

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Запустите приложение**

   ```bash
   flask --app app run --debug
   ```

   По умолчанию сервер будет доступен по адресу <http://127.0.0.1:5000>.

3. **C++ санитайзер сообщений** компилируется автоматически при первом запуске или отправке сообщения. При необходимости вы можете собрать его вручную:

   ```bash
   g++ -std=c++17 -O2 cpp/message_sanitizer.cpp -o cpp/build/message_sanitizer
   ```

## Структура проекта

```
.
├── app.py                 # Точка входа Flask-приложения
├── mamontov_com/
│   ├── __init__.py        # Фабрика приложения
│   ├── models.py          # SQLAlchemy модели пользователей и сообщений
│   ├── routes.py          # Веб-маршруты и REST API для чата
│   ├── sanitizer.py       # Обёртка для C++ санитайзера
│   ├── templates/         # HTML-шаблоны
│   └── static/            # Стили и JavaScript
├── cpp/
│   └── message_sanitizer.cpp  # Очистка текстов на C++
└── requirements.txt
```
